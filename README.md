# AR Card Popup

This project uses MindAR image tracking to display a video
when a supported card image is detected.

## Live Website

https://chaitanya-karri.github.io/card-popup/

## How to Use

1. Open the live website using a mobile browser.
2. Allow camera permission.
3. Press Start Camera.
4. Point the camera at one of the target card images.
5. The matching video will appear over the card.

## Files

- `index.html` - AR website
- `targets.mind` - MindAR compiled image targets
- `cards.json` - Card metadata
- `assets/` - Card images and videos

## Important

Camera access generally requires HTTPS.
GitHub Pages provides HTTPS automatically.
